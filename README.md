# Ethisyn

> **We build software, automate your operations, and help your business grow online.**

Official web platform for [Ethisyn](https://ethisyn.in) — an independent product engineering and digital systems studio started as an idea in Hyderabad in 2022.

---

## What We Do

1. **Websites & Software**: High-speed business websites, web applications, mobile apps (iOS & Android), SaaS MVPs, and e-commerce stores.
2. **AI & Business Automation**: 24/7 AI voice agents answering calls, WhatsApp & web chatbots, CRM integrations, and automated workflows.
3. **Digital Growth & SEO**: Top Google Search rankings, Google Maps local domination, AI Search Optimization (GEO), social media, and analytics.
4. **Creative, Design & Video**: Figma UI/UX prototypes, brand identity & logos, short-form video reels, and sales presentations.
5. **Business Systems & Cloud**: Custom CRM architectures, live performance dashboards, internal team tools, and secure cloud setups.
6. **Support & Maintenance**: 24/7 uptime monitoring, sub-second speed optimization, security updates, and on-demand engineering support.

## Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, Server Components)
- **UI & Styling**: [React 19](https://react.dev/), [Tailwind CSS](https://tailwindcss.com/)
- **Typography**: Instrument Sans, Instrument Serif, IBM Plex Mono
- **Validation**: [Zod](https://zod.dev/)
- **Testing**: [Vitest](https://vitest.dev/), [Playwright](https://playwright.dev/), [Axe-Core](https://github.com/dequelabs/axe-core)
- **Email Delivery**: [Resend](https://resend.com/)

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
```bash
cp .env.example .env.local
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## Commands

- `npm run dev`: Starts local development server.
- `npm run build`: Compiles production build.
- `npm run typecheck`: Validates TypeScript types without emitting code.
- `npm run lint`: Runs ESLint checks.
- `npm test`: Runs Vitest unit & component test suite.
- `npm run test:e2e`: Runs Playwright browser & accessibility tests.
